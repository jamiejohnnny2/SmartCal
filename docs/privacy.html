Smart Calendar — Privacy Policy

Last updated: 2026-09-18

Smart Calendar is a self-hosted, single-household application. This policy describes what data it accesses through Google's APIs, and what happens to that data.

What it accesses

With permission from each Google account that a household member links, Smart Calendar requests:

  • Google Calendar (read/write) — to display upcoming events on the household's shared screen, and to create, edit, or delete events when a household member adds one from that screen.
  • Basic account info (email address) — to label which linked account each calendar belongs to inside the app.

Where it's stored

All calendar data and account credentials are stored locally on the household's own Raspberry Pi, on their own home network. Nothing is sent to, or stored on, any server operated by the developer or any third party. There is no central or shared backend — each household runs its own independent copy of this software on its own hardware.

Who it's shared with

Nobody. This data is never sold, shared, or transmitted to any third party, advertiser, or analytics service. The only communication is directly between the household's own device and Google's Calendar API, using each linked account's own authorization.

Retention and removal

Data persists only on the household's own device for as long as an account stays linked. Unlinking an account from the app immediately removes its stored calendar data and credentials from that device. A household member can also revoke access at any time from their Google Account permissions page.

Contact

Questions about this app or policy can be raised via the project's GitHub repository.
