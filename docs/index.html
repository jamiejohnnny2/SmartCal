Smart Calendar

A private household calendar hub for a Raspberry Pi touchscreen.

Smart Calendar is a self-hosted app that links one or more Google accounts belonging to a single household, merges their calendars into one always-on display, and lets household members add events from a touchscreen that get written back to the right person's Google Calendar.

It runs entirely on hardware owned by the household that set it up — there is no shared public service, and no data is available to or used by anyone outside that household.

See the privacy policy for details on what data this app accesses and how it's used.
